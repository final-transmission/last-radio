==================================================================
 최후의 무전 — 동료(영입 NPC) 확장용 자료 (설정·스크립트 의뢰서)
==================================================================

게임에 영입 가능한 동료(NPC)의 특성·대사·영입 이벤트를 늘리기 위한 자료입니다.
맨 아래 「제출 형식」에 맞춰 써 주면 그대로 게임에 넣을 수 있습니다.

------------------------------------------------------------------
0. 게임 개요와 문체
------------------------------------------------------------------
- 좀비 아포칼립스 생존 웹게임(멀티플레이). 배경: LA → 모하비 사막 → 라스베이거스 → 덴버 → 시카고 → 뉴욕.
- 분위기 참고: 워킹데드, 라스트 오브 어스, 프로젝트 좀보이드.
- 현실 30분 = 게임 하루. 좀비는 주로 '워커'·'놈들'이라고 부른다.
- 일지 문장은 1인칭 관찰 시점, 과거형, 짧고 건조하게(주어 생략).
- 동료 대사는 큰따옴표 안의 한 문장(최대 두 문장). 반말·존댓말은 캐릭터에 맞게 자유.
- 수치(체력 -12 등)는 게임이 자동으로 붙이니 결과 표현만 따로 적을 것.

------------------------------------------------------------------
1. 동료 시스템 규칙 (지금 동작)
------------------------------------------------------------------
- 동료는 한 번에 1명만. 이미 있으면 새로 영입되지 않고 "각자 길을 가기로 했다"로 끝난다.
- 동료는 이름·특성·체력(100)·배고픔(0~3)을 가진다. 플레이어가 이동하면 따라온다.
- 매일: 체력 +2 회복. 50% 확률로 배낭에서 음식 1개를 먹는다(개는 개 사료·생고기·육포 우선).
  먹을 게 없으면 배고픔 +1 → 배고픔 3이면 떠난다(떠날 때 대사).
- 좀비와 싸울 때 20% 확률로 대신 맞는다(피해의 절반쯤을 떠안음). 체력 0이면 죽는다(죽을 때 대사 + 애도 문장).
- 플레이어가 「헤어지기」를 누를 수 있다. 플레이어가 죽고 다시 시작하면 동료는 사라진다.
- 개(dog)는 말을 하지 않는다(대사 대신 행동 묘사).

------------------------------------------------------------------

4. 지금 있는 대사 풀 (특성과 상관없이 공용)
------------------------------------------------------------------

[join] 영입될 때
- 혼자 다니는 것보단 낫겠지. 서로 뒤통수만 치지 말자.
- 나를 데려가도 후회하지 마. 쓸모는 있을 테니까.
- 정말 같이 가도 돼? ...고마워. 진심이야.
- 살아남는 데 필요한 건 서로 믿을 사람 하나뿐이야.
- 혼자 살아남는 데는 한계가 있어. 앞으로 잘 부탁해.
- 내가 도움이 될 수 있다면 같이 갈게.
- 믿어 달라고는 안 할게. 대신 행동으로 보여 주겠어.

[hungry] 배고플 때
- 오늘 먹을 건 남아 있어? 빈속으로는 더 못 걷겠어.
- 괜찮아. 내 몫은 줄여도 돼. ...아니, 괜찮다는 건 거짓말이야.
- 사흘째 제대로 먹지 못했어. 이러다 좀비보다 먼저 쓰러지겠어.
- 다른 건 몰라도 물은 좀 구해야겠어.
- 오늘 먹을 건 있어? 나도 더는 버티기 힘들어.
- 네 몫까지 빼앗고 싶지는 않아. 하지만 정말 배가 고파.
- 먹을 게 없다면 사냥이라도 나가자. 여기서 굶어 죽을 순 없어.

[leave] 떠날 때(굶주림·헤어지기)
- 여기서 헤어지자. 더는 네 선택을 믿을 수 없어.
- 미안해. 같이 가고 싶지만, 지금은 내 목숨부터 챙겨야겠어.
- 살아남으면 다시 만나자. 그때까지 죽지 마.
- 다음에는 누군가를 믿는 게 조금 덜 무서웠으면 좋겠어.
- 미안해. 더는 여기서 버틸 수 없어.
- 다음에 만나도 서로 적이 되지는 말자.
- 우린 살아남으려고 함께했어. 이제는 각자 살아남아야 해.

[death] 죽을 때
- 잠깐만... 아직 할 말이...
- 나 두고 가지 마. 제발...
- 끝까지 같이 가기로 했잖아...
- 눈을 감지 마. 아직... 아직 끝난 게 아니야.

[mourn] 죽은 뒤 플레이어의 애도 문장
- 대답해 봐. 제발, 한 번만 더 대답해 줘.
- 이럴 줄 알았으면 마지막에 좀 더 이야기할걸.
- 너를 두고 가는 게 맞는지 모르겠어. 하지만 움직여야 해.
- 미안해. 네가 지키려던 것까지 내가 기억할게.

5. 지금 동료가 생기는 곳 (영입 경로)
------------------------------------------------------------------
- 무전 임무: 구조(rescue) 임무에서 "함께 가자"를 고르면 영입(특성 무작위). 치료(medic) 임무 성공 시 60% 영입.
- 조사 이벤트: 🩸 숨어 있던 생존자(bitten), 🚪 문 너머의 생존자(plea), 불난 아파트(fireapt) — 특성 무작위
- 산불 대피소(wildfire_shelter) → 사냥꾼 / 바리케이드 학교(barricaded_school) → 간호사 / 옥상 신호(rooftop_signal) → 경비원
- 아이들 구조 임무(mis_rescue_children) → 짐꾼 / 옥상 구조 임무(mis_rescue_rooftop) → 경비원 또는 무작위
- 🐕 떠돌이 개(dog) 이벤트 → 개
- 대부분 지역 제한 없이 나온다. LA 밖 지방 전용 영입 이벤트는 아직 없다.

6. 효과를 연결할 수 있는 게임 시스템 (새 특성 제안 때 참고)
------------------------------------------------------------------
- 조사: 좀비와 마주칠 확률, 찾는 물자 양, 무기·도구·의료품 발견 확률, 백신 발견
- 싸움: 받는 피해, 상처 없이 넘길 확률, 처치 확률, 무기 내구도 소모
- 사냥·채집·농사: 성공률, 수확량
- 몸: 체력 회복, 감염 진행 속도, 상처 회복 속도, 피로 회복, 갈증·배고픔 소모
- 제작·수리: 두 배로 만들 확률, 수리량, 필요 재료
- 이동: 이동 시간, 이동 중 조우 확률, 탈것 연료 소모
- 무전: 임무 무전을 더 잘 잡음, 잡음(글자 깨짐) 감소
- 떠돌이 상인: 교환 횟수 +1, 값 할인
- 쉘터: 창고·시설 생산량
- 기술 경험치: 수색·근접전·사격·의술·요리·정비 (최대 10레벨)

 의뢰 내용
==================================================================
1) 새 특성 8~12개: 위 6장의 시스템에 연결되는 효과로. (예: 요리사, 전직 군인, 약사, 트럭 운전사, 아이, 기자, 목사, 전직 죄수, 엔지니어, 고양이 등)
2) 특성별 고유 대사: 기존 특성 11개 + 새 특성 모두. 상황마다 3~5줄씩 (영입·배고픔·떠남·죽음, 그리고 아래 새 상황).
3) 새 대사 상황(선택): 함께 쉴 때(잡담), 플레이어가 다쳤을 때, 좀비를 쓰러뜨렸을 때, 밤이 됐을 때, 새 지방에 들어설 때, 뉴욕 쉘터 도착 때.
4) 이름 20~30개 추가: 다양한 국적·나이. 한국어 표기.
5) 영입 이벤트 10~15개(선택형): 일부는 지방 전용(모하비·라스베이거스·덴버·시카고·뉴욕). 영입 실패·함정 결과도 섞을 것.
6) 동료 동행 이벤트 8~12개(선택형): 동료가 있을 때만 나오는 이벤트(다툼, 부탁, 과거 고백, 감염 숨김, 배신, 가족 찾기 등).
7) (선택) 동료 신뢰도 같은 새 규칙 제안: 짧게, 어떤 행동으로 오르내리는지.

 제출 형식
==================================================================

■ G. 새 특성
id: 영문 소문자 (예: cook)
이름: 한국어 (예: 전직 요리사)
효과: 위 6장 시스템 중 하나 + 수치 제안 (예: 굽기·끓이기 때 두 배로 만들 확률 +15%)
먹는 것(선택): 우선해서 먹는 음식 id (없으면 일반 음식)
말하는가: 예/아니오 (동물이면 아니오)

■ H. 특성별 대사
특성 id: (기존 id 또는 새 id)
상황: join / hungry / leave / death / mourn / chat / hurt / kill / night / newregion / nyarrive
대사: 한 줄씩 3~5개 (따옴표 없이 대사만)

■ I. 영입 이벤트 (선택형)
id: 영문 소문자 고유 이름
장소: 지역/건물/지점 id 목록 또는 '어디서나' (지방 전용이면 지방 이름도 적기)
비중: 1~3
제목: 이모지 + 짧은 제목
본문: 상황 묘사 1~2문장
선택지: 2~3개 (각 15자 이내)
결과: 선택지마다 문장 + 결과 표현. 영입은 "동료 영입 (특성 id, 확률 n%)"처럼.

■ J. 동료 동행 이벤트 (동료가 있을 때만)
id / 장소 / 비중 / 제목 / 본문 / 선택지 / 결과 : I와 같음
조건(선택): 특정 특성일 때만, 동료 체력이 낮을 때 등
결과 표현 추가: "동료 체력 -n", "동료가 떠난다", "동료 죽음", "동료 배고픔 0으로"

■ 결과 표현
- 체력 -a~b (부상: 타박상/할큄/열상/물림 또는 '싸움'·'사람')
- 피로 +n / -n, 수분 -n, 포만감 -n
- 획득: 아이템 id 목록에서 n개 / 잃음: 음식·음료·의료품·도구 n개 또는 특정 id
- 아이템 사용 필요: 예) bandage가 있으면 1개 써서 ~ / 없으면 ~
- 처치 +n, 감염 +n%, 기술 경험치(수색/근접전/사격/의술/요리/정비) +n
- 확률: "40%: ~ / 나머지: ~"
